# 編集アシスタント（Premiere Pro UXPパネル）

マニュアル準拠のチェック・テロップ生成・音声設定・カット記録を、Premiere Pro のパネル内で行います。

**「トンマナ パレット」とは別パネルです。** 役割を分けています。

| パネル | 役割 |
|---|---|
| トンマナ パレット（既存） | クリップ素材（テロップ・画像・SE・BGM）の挿入 |
| **編集アシスタント（これ）** | マニュアル準拠チェック・テロップ生成・音声設定・カット記録 |

---

## 画面

| タブ | 内容 |
|---|---|
| **素材確認** | 素材確認12項目のチェック。結果の連絡テンプレートを出力してコピー |
| **提出前** | 正式18項目＋改善候補12項目＋切り抜き12項目。改善候補は正式と分けて表示 |
| **テロップ** | 文字起こし／SRT／VTT を貼り付けてテロップ行へ整形。表記揺れも同時に検査 |
| **演出** | 演出が要る位置を計算し、シーケンスへマーカーを打つ（位置だけ。中身は決めない） |
| **音声設定** | 演者 -6.0dB / SE -20.0dB / BGM -29.0dB の早見表と設定順 |
| **カット記録** | 本カット後の修正箇所を記録。PDCAの入力データになる |

---

## インストール

### 開発中（UDT を使う）

1. [UXP Developer Tool](https://developer.adobe.com/photoshop/uxp/devtool/) を起動
2. **Add Plugin** → この `uxp-plugin/manifest.json` を選択
3. **Load** を押す
4. Premiere Pro の `ウィンドウ` メニューに「編集アシスタント」が追加される

### 配布用

UDT の **Package** から `.ccx` を作成し、配布・インストールします。

---

## 動作要件

- Premiere Pro 25.0 以降（UXP対応版）
- Mac / Windows 両対応

2024以前の Premiere をお使いの場合、UXP が使えないため CEP 拡張（ExtendScript）へ移植が必要です。その場合は `adapter.js` の中身だけを書き換えます。

## ファイル構成

```
uxp-plugin/
  manifest.json     UXPマニフェスト
  index.html        パネルの骨組み
  styles.css        スタイル（Premiereの暗いテーマ / 明るいテーマ両対応）
  app.js            画面生成と操作
  telop.js          テロップ整形ロジック（依存なし・単体で使える）
  adapter.js        ★ Premiere API を呼ぶ処理はここだけ
  data/
    manual-snapshot.js   マニュアルデータ（自動生成。手で編集しない）
```

### データの更新

マニュアルを更新したら再生成してください。

```bash
node tools/build-plugin-data.mjs
```

`video-manual-visualizer/manual-data.js` が唯一の情報源です。スナップショットは生成物なので、直接編集しないでください。

## ⚠ Premiere API について

`adapter.js` 内の `premierepro` API 呼び出しは、**Premiere Pro 実機での動作確認をしていません。**

UXP の API はバージョンによって差異があるため、初回起動時に調整が必要な可能性があります。調整は `adapter.js` の中だけで完結し、UI とロジック（`app.js` / `telop.js`）には影響しません。

対象は次のメソッドです。ファイル内で `ここから Premiere API（未検証）` とコメントしてあります。

| メソッド | 用途 |
|---|---|
| `getActiveSequence()` | シーケンス名・トラック数・再生位置 |
| `findProjectItem(name)` | プロジェクトパネルからアイテム検索 |
| `insertAtPlayhead()` | 再生ヘッド位置へクリップを上書き挿入 |
| `getPlayheadTimecode()` | 再生位置のタイムコード取得 |
| `addMarker()` | シーケンスマーカーの追加 |
| `insertTelops()` | テロップの一括配置（MOGRT / SRT） |
| `inspectTextLayers()` | 既存テロップの調査（読み取りのみ。変更しない） |
| `addDirectionMarkers()` | 演出スロットへマーカーを一括で打つ |

### `inspectTextLayers()` について

「段落テキストをポイントテキストへ変えたい」のように、**APIで触れるかどうかが
確認できていない操作**を頼まれたときのための調査用です。

指定シーケンスの指定トラックにあるクリップを開き、`TrackItem` →
`ComponentChain` → `Component` → `ComponentParam` と辿って、その環境の
API が実際に公開しているメソッド名・パラメータ名をそのまま書き出します。

**変更は一切行いません。** 呼び方は版によって違うため、候補を順に試して
通ったものを使い、通らなかった呼び出しも結果に残します。

分からないままAPIを呼ぶコードを書くと、動かなくても動いたように見えます。
先に事実を取ってから実装する、という順番のためのメソッドです。

**Premiere が無い環境では自動的にモックへ切り替わります。** ヘッダーに「接続: モック」と表示され、挿入やマーカー追加は実行されません。UI の動作確認はブラウザでできます。

```bash
cd uxp-plugin
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 設計方針

| 方針 | 理由 |
|---|---|
| `innerHTML` を使わない | DOM生成は `createElement` / `textContent` のみ。貼り付けたテキストがそのままDOMになる事故を防ぐ |
| Premiere API を1ファイルに隔離 | API差異の吸収を1箇所に閉じ込め、UIとロジックを守る |
| 文章を書き換えない | 話し言葉をそのまま残す指示があるため。整えるのは改行位置と表記だけ |
| 改善候補を正式チェックと分離 | 正式18項目に混ざるのを防ぐ。バッジと枠で明確に区別 |
| 矛盾を解決しない | 演出頻度と提出方法は未決定。両方を表示して確認を促す |
| チェック状態を保存しない | パネルを開いている間だけ保持。仕様どおり |

## 検証

320px 未満にはならないため、Premiere の最小パネル幅 300px と既定ドック幅 420px で確認しています。

| 項目 | 結果 |
|---|---|
| JSエラー | なし |
| 素材確認12項目 / 提出前18・12・12項目 | 表示・チェック・進捗更新すべて動作 |
| テロップ整形 | 句読点除去・全角変換・15〜18文字分割を確認 |
| SRT取り込み | タイムコード保持を確認 |
| 表記揺れ検査 | 122件の辞書と照合、検出を確認 |
| カット記録 | 記録・傾向集計を確認 |
| 横方向のはみ出し | 0px（両幅） |
| 最小文字サイズ | 10px以上を維持 |

**両幅とも全項目合格しています。** ただし前述のとおり、Premiere 実機での API 動作は未確認です。
