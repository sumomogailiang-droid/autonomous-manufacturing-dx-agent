# 文字起こし依頼プロンプト（Codex用）

`tools/segment-kit.mjs` がそのまま読める形で文字起こしを出させるためのプロンプトです。
下の「---」から下を丸ごとコピーして、音声ファイルと一緒に Codex へ渡してください。

## なぜこの形式を要求するのか

| 要求 | 理由 |
|---|---|
| ミリ秒つきSRT | フレーム換算に必要。29.97fpsで1フレーム＝約33ms。秒単位だと1フレームずれる |
| 1発話1キュー | カット候補の検出（相槌・ケバ・復唱）が発話単位で動くため |
| 同時発話は重ねたまま | 重なりを検出して上のトラックへ逃がす処理の入力になる。直列化されると壊れる |
| 相槌・ケバも省略しない | 削られるとカット候補として提案できなくなる。消すのは編集者の判断 |
| 話し言葉そのまま | 共通マニュアルの明記事項。整えるのは改行位置と表記だけ |
| 話者ラベル | 工程7（演者ごとのテロップ色分け）が映像を見ずに埋まる |

# 文字起こし依頼

添付の音声を、下の仕様どおりに文字起こししてください。
**この出力はフレーム単位で字幕を配置するツールへ直接入力されます。仕様から外れると使えません。**

## 対象範囲

`00:03:10.030` 〜 `00:06:10.520`（約3分）

## 出力形式

SRT形式。**それ以外の文章・前置き・説明を一切付けないでください。**

```
1
00:03:10,030 --> 00:03:12,400
あおさん: はい ということで名古屋校にやってまいりました。

2
00:03:12,400 --> 00:03:13,100
松井さん: はい。

3
00:03:12,900 --> 00:03:14,500
ササさん: おめでとうございます。
```

- タイムコードは `HH:MM:SS,mmm`（**ミリ秒3桁まで必須**）
- 本文の先頭に `話者名: ` を付ける（半角コロン＋半角スペース）
- 番号 → タイムコード → 本文 → 空行、の順を厳守

## 絶対に守ること

### 1. 話し言葉をそのまま書く

書き換え・整文をしないでください。

| ○ そのまま書く | ✗ 直さない |
|---|---|
| 回してます | 回しています |
| ちょっと待って | 少々お待ちください |
| なんか、あれだって | なんというか、あのようなことだと |

言い間違い・言い直しもそのまま残します。

### 2. 相槌・ケバを省略しない

「はい」「うん」「なるほど」「えーと」「あのー」も**1つ残らず**書き起こしてください。
短いからといって飛ばさないこと。**これらを消すかどうかは編集側が決めます。**

### 3. 同時発話は重なったまま出す

2人が同時に喋っている箇所は、**タイムコードを重ねたまま**別々のキューにしてください。
順番に並べ替えたり、片方を削ったりしないでください。

```
66
00:01:29,550 --> 00:01:32,590
あおさん: はい ということで名古屋校にやってまいりました。

67
00:01:30,000 --> 00:01:31,000
松井さん: おめでとうございます。
```

↑ 67番が66番の途中から始まっているのが正しい状態です。

### 4. 1つの発話を1つのキューにする

複数の発話を1キューにまとめないでください。話者が替わったら必ずキューを分けます。
長い発話は、息継ぎや文の切れ目でキューを分けて構いません。

### 5. 話者名は一貫させる

同じ人物には最後まで同じ表記を使ってください。

**誰か分からない場合、名前を推測しないでください。** `話者A` `話者B` `話者C` を使います。
名前が音声中で明示された場合のみ、その名前を使ってください。

### 6. 句読点は普通に付ける

「、」「。」はそのまま付けてください。字幕用の変換はツール側で行います。

### 7. 固有名詞は聞こえたまま

裏取りできない固有名詞は、聞こえた音をそのままカタカナ等で書いてください。
**推測で漢字を当てないでください。**

聞き取れない箇所は `［聞き取り不明］` と書きます。無音で埋めないこと。

### 8. 数字は聞こえたまま

「20万円」を「200,000円」に直したり、「1時間」を「60分」に換算したりしないでください。

## 出してはいけないもの

- 要約・見どころ・章立て
- 「以下が文字起こしです」などの前置き
- 話者の心情や状況の補足（`（笑）` は音として笑い声がある場合のみ可）
- 内容の言い換え・意訳

## 提出前に自分で確認すること

1. 先頭が `1` で始まり、SRT以外の文字が1つも混ざっていないか
2. 全タイムコードにミリ秒3桁があるか
3. 全キューの本文に `話者名: ` が付いているか
4. 相槌（はい・うん・なるほど）を省略していないか
5. 同時に喋っている箇所でタイムコードが重なっているか
6. 話者名の表記が最後まで揺れていないか

## 受け取ったあとの流れ

SRTを受け取ったら、そのまま次を実行します。

```bash
node tools/segment-kit.mjs produce <SRT> --in 00;03;10;03 --out 00;06;10;29
```

出るもの:

| 工程 | 担当 | 成果物 |
|---|---|---|
| 4・5 | cutter | `cut-candidates.md` カット候補（フレーム番号・種類・根拠・確度） |
| 6・7 | telop | `telop-plan.md` テロップ配置（フレーム確定・同時発話のレイヤー分け・演者列） |
| 7 | project-manual | `speakers.md` 演者一覧と色割当表 |
| 表記 | common-manual | `notation.md` 辞書122件との照合 |
| 比較 | observer | `stats.md` 冒頭3分の基準値との差分 |

## フレームレートの確認事項

指定いただいた `00;06;10;52` は、**29.97fpsでは存在しない値**です
（29.97のフレーム番号は 00〜29 まで）。59.94fps なら正しい値になります。

| fps | `00;06;10;52` の解釈 | 往復確認 |
|---|---|---|
| 29.97 | 371.705秒 | `00;06;11;22` ✗ 一致しない |
| 59.94 | 370.837秒 | `00;06;10;52` ○ 一致する |

**シーケンスのフレームレートを確認してください。** 59.94fps の場合は次のように指定します。

```bash
node tools/segment-kit.mjs produce <SRT> --in 00;03;10;03 --out 00;06;10;52 --fps 59.94
```

フレームレートを間違えると全キューがずれます。ここは推測で進めません。
