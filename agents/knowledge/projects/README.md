# 案件マニュアル置き場

このディレクトリには、案件ごとの知識ベースが生成されます。

**中身はGitへコミットされません**（`.gitignore` で除外）。
クライアント情報を含むため、意図的に共有対象から外しています。

## 生成方法

```bash
node agents/generate-project-agent.mjs <案件マニュアルのパス> <案件ID> "<案件名>"
```

例:

```bash
node agents/generate-project-agent.mjs ./manuals/camp-nagoya.md camp-nagoya "CAMPチャンネル 名古屋校"
```

## 生成後にやること

生成されたファイルには「確認が必要」「未記入」の箇所があります。
これは自動検出した上書き候補で、**まだ確定していません**。

原文を見ながら次を確定させてください。

1. 上書き候補の表 — 共通マニュアルと違う数値のうち、実際に採用する値
2. 共通マニュアルの未決定事項 — 演出頻度（6秒 vs 10秒）と提出方法（Frame.io vs 限定公開）

未確定のまま案件別の判断をすると、エージェントは「確認が必要」と回答します。
`list_projects` で未確定件数を確認できます。
