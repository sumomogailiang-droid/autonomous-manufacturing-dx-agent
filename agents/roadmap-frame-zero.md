# PROJECT: FRAME ZERO — 完全自動化ロードマップ

会社: **ENGULF（エンガルフ）**
目標: **高品質な動画編集の完全自動化。フレームずれゼロと、人の手数ゼロを両立させる。**

このドキュメントは、共通マニュアル（全13工程・数値基準36件・提出前チェック18項目）と
案件マニュアルの構造を根拠に、既存エージェントの守備範囲と足りない人材を分析したもの。
推測で書いた行には必ず「要検証」と付けている。

## 3. フェーズ計画

### Phase 1 — 人材と観察（今回）
- observer / recruiter / cutter / mixer を配属 ✅
- observerが修正指示の蓄積を開始し、ニュアンスの言語化を始める

### Phase 2 — Premiere接続
- adapter.js の実機検証（工程3・7の完全自動化に必須）
- UXPプラグインから操作ログを出し、observerのリアルタイム観察を実装
- cutterのカット候補をプラグインでワンクリック適用

### Phase 3 — 学習と閉ループ
- observerの記録 → recruiter/directorの判断 → パラメータ更新の循環
- 修正指示ゼロ（工程12の理想値）を測定可能な目標にする

### 常に守る前提
- 未決定の矛盾（演出頻度・提出方法）は自動化で勝手に解決しない
- 改善候補は正式ルールに混ぜない
- ニュアンスの最終判断は人 → observerが記録 → 徐々に候補提案の精度を上げる
- 承認なしの新役割配属は監査（C5-17）が止める
