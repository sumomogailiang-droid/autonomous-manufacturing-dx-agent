# 動画編集者 全体マニュアル ビジュアライザー

動画編集者の全体マニュアルを、**中学生や動画編集初心者でも理解できる**インタラクティブなWebページに変換した静的アプリです。

依頼を受けてから納品・修正・保存するまでの全工程を12画面に分解し、各工程で「何をするか／なぜ必要か／よくある失敗／完了条件／関連マニュアル」を確認できます。

---

## 起動方法

ビルド不要・依存パッケージなしの静的HTMLです。

### 方法1：ファイルを直接開く

```bash
open video-manual-visualizer/index.html        # macOS
xdg-open video-manual-visualizer/index.html    # Linux
start video-manual-visualizer\index.html       # Windows
```

### 方法2：ローカルサーバーで開く（推奨）

```bash
cd video-manual-visualizer
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

Node.jsを使う場合：

```bash
cd video-manual-visualizer
npx serve .
```

## 情報の分類

すべてのルールを4種類に分類し、**バッジで区別**しています。改善候補を正式ルールへ混ぜていません。

| バッジ | 意味 |
|---|---|
| ✓ **正式記載** | 元マニュアルに明記されているルール |
| ◆ **案件依存** | 案件マニュアル・チャンネルルール・ディレクター判断が優先 |
| ⚠ **矛盾・要決定** | マニュアル内で複数の基準が衝突している |
| ＋ **改善候補** | 現行マニュアルに正式ルールとして存在しない。事故防止のため検討すべき内容 |

色だけで意味を伝えないよう、**記号（✓ ◆ ⚠ ＋）とラベル文字を必ず併記**しています。

## 検出した矛盾・欠損（監査画面に表示）

### 矛盾

1. **演出頻度** — 「演出・よくあるミス：6秒に1回」と「提出前チェック：10秒に1回」が衝突。どちらが正式基準か未決定。
2. **提出方法** — 4箇所で記載が衝突。提出シート冒頭「Frame.ioへ統一」／チェック「YouTube限定公開を提出」／提出シート後半「限定公開手順が残存」／修正「限定公開の概要欄を使用」。
3. **音声エフェクトの数** — 冒頭は3種類のみ列挙だが、後から4種類目（ステレオエクスパンダー）が登場。
4. **グリーンバックの手順番号④が重複。**
5. **SEの指数フェード** — 「SE本体には入れない」と「クリックノイズ対策では指数フェードへ切り替える」が混同しやすい記載。

### 目次の問題（6件）

「通常画角」「改行位置」のリンク先タブが存在しない／「提出」の目次リンクが旧シートID／「マルチカメラ設定」「エンタメ演出」「見出し・サブ見出し作成」が目次にない。

### 欠損リンク（5件）

MTSファイル解説URL／FrameDetector解説URL／マルチカメラ応用URL／限定公開設定の動画解説／Add MarkerのURL。

**URLは一切推測していません。** 検証スクリプトで、データ内に `http(s)` URLが1件も存在しないことを機械的に確認しています。

## 設計方針

### 外部通信をしない

- 外部APIやGoogleスプレッドシートへの `fetch` は行いません。
- 全データを `manual-data.js` にローカル保持しています。
- 外部CDN（フォント・ライブラリ）に依存しません。フォントはシステムフォントのみ。
- 外部リンク先を自動取得しません。

### セキュリティ

- ユーザー入力を `innerHTML` へ入れません。DOM構築は `createElement` と `textContent` のみです。
- 検索欄の入力値は、フィルタ条件としてのみ使用します。

### アクセシビリティ

- 日本語UI。
- 320px幅のスマートフォンからデスクトップまで対応。
- ライトモード・ダークモード対応（システム設定に追従、手動切り替えも可能）。
- 色だけで意味を伝えません（記号とラベル文字を併記）。
- キーボード操作可能（タブは矢印キー・Home・Endで移動）。
- フォーカス表示を消していません。
- 文字は最低11px相当以上。
- 長い横一列のフローを作らず、画面幅に応じて最大4列で折り返します。
- グラフには数値と単位を直接表示します。
- 自動再生アニメーションを使いません。`prefers-reduced-motion` に対応しています。
- コピー結果を画面上のトーストで通知します（`role="status"` / `aria-live="polite"`）。

### 状態の扱い

提出前チェックの状態は**メモリ上のみ**で保持します。ページを再読み込みすると外れます（仕様どおり）。

## 残っている制約

- **演出頻度と提出方法の矛盾は解消していません。** 元マニュアルで未決定のため、勝手に統一せず「要決定」として両方を表示しています。運用を決めるのはディレクターの判断です。
- **欠損しているURLは補っていません。** 推測を禁止されているため、「参照先欠損」として表示するのみです。
- **AIへ入力してよい情報の範囲は未定義です。** Google AI Studio・Vrew・ChatGPT・Geminiの利用が推奨されている一方、入力可否のルールが記載されていないため「要確認」として表示しています。
- **集計値は原文記載の実測値のみを使用しています。** 架空の品質スコアは作成していません。
- 元マニュアルの「動画制作手順」は工程16で終わっているため、その先（提出前チェック〜1年間保存）は改善候補として明示的に区別して接続しています。
